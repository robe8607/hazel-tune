# Hazel Tune

A guitar tuner for 6- and 12-string guitars, plus a piano and guitar trainer: follow-along sheet-music mode that listens to your real instrument, a Song → Piano arranger that turns any song into a dueling-piano version, melody learning by ear, and Send a tune links. By Hazel Management LLC.

Open it on your phone, tap **Start tuning**, allow the microphone, and pluck a string. To install it like an app on iPhone: open the link in Safari → Share → **Add to Home Screen**.
